# RESEARCH_REFERENCES (Song Critic Academy V1)

Researched 2026-11-12 with web search and page fetches (WebFetch / WebSearch). What was verified is exactly what a page or listing says; no book was read in full, and nothing was copied from a source (the lessons are written in our own words).

## Three kinds of content (kept apart in every lesson)
1. **A principle that a reference supports**: marked `[R1]`, `[R2]` ... in the text. Only claims that the checked page actually makes (for example "the course has a lesson on X", "the excerpt describes object writing as Y") carry a tag.
2. **Our own synthesis** (application advice, the eight opening patterns, the six development approaches, the six functions of repetition, the six endings, the sentence-level cautions): no tag, and the References section says so with a `status: general` entry.
3. **Teaching examples**: Thai lines written for the lessons ("แต่งขึ้นเพื่อการสอน" / "written for teaching"). They are not quotations from real songs.
The eight opening patterns and the other groupings are categories we made for learning; no lesson calls them an academic classification.

## Scope of the label "Source checked"
In the app, a reference marked "Source checked" means that the page or listing named in the line was looked up and the sentence after it says what that page shows. It does not mean the book was read. Each reference line states its own limit (for example "we have not read the book itself").

## Provenance of the examples
All Thai example lines are original, written for these lessons. None was copied from a real song or from a source. Existing test songs of earlier audits are not used as lesson examples.
